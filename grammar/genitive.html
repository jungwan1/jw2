생격 (Родительный падеж)

🔊 러시아어를 누르면 소리가 나요. 연습 칸은 누르면 답이 보여요.

1. 명사 생격 어미 (단수)

생격은 "~의", "~이 없다", 수량, 일부 전치사 뒤에 써요.

남성 자음 끝+а
남성 -й / -ь-я
여성 -а-ы
여성 -я / -ь-и
중성 -о / -е-а / -я

к, г, х, ж, ш, щ, ч 뒤에서는 -ы 대신 -и (книга → книги).

주격생격
брат형제бра́та
музе́й박물관музе́я
сестра́자매сестры́
кни́га책кни́ги
неде́ля주неде́ли
тетра́дь공책тетра́ди
сло́во말씀, 단어сло́ва
мо́ре바다мо́ря

🎯 패턴 연습 (눌러서 확인)

сестра → 생격сестры́
брат → 생격бра́та
неделя → 생격неде́ли
слово → 생격сло́ва

2. 소유 "~의"

소유하는 쪽을 생격으로 써서 뒤에 놓아요.

예문

  • Э́то кни́га бра́та.
    이것은 형의 책이에요.
  • Сло́во Бо́га.
    하나님의 말씀.
  • Дом сестры́ ря́дом.
    언니의 집은 가까워요.

🎯 패턴 연습 (눌러서 확인)

книга + браткни́га бра́та
дом + сестрадом сестры́

3. нет + 생격 "~이 없다"

현재 없음은 нет, 과거는 не было, 미래는 не будет + 생격.

예문

  • У меня́ нет бра́та.
    나는 형제가 없어요.
  • Здесь нет кни́ги.
    여기 책이 없어요.
  • Вчера́ не́ было вре́мени.
    어제는 시간이 없었어요.

вре́мя시간 → вре́мени (불규칙)

🎯 패턴 연습 (눌러서 확인)

брат 없다нет бра́та
книга 없다нет кни́ги
сестра 없었다не́ было сестры́

4. 전치사 + 생격

из~에서(밖으로)
от~로부터
до~까지
без~없이
для~을 위해
у~의 곁에, ~에게(있다)

예문

  • Я из Коре́и.
    나는 한국에서 왔어요.
  • Письмо́ от сестры́.
    언니에게서 온 편지.
  • Без стра́ха.
    두려움 없이.
  • Пода́рок для бра́та.
    형을 위한 선물.

Коре́я한국 письмо́편지 страх두려움 пода́рок선물

🎯 패턴 연습 (눌러서 확인)

без + страхбез стра́ха
для + сестрадля сестры́
из + Кореяиз Коре́и

5. 수량과 생격

2·3·4 뒤에는 단수 생격, 5 이상과 много/мало 뒤에는 복수 생격.

예문

  • Два бра́та.
    형제 두 명.
  • Три кни́ги.
    책 세 권.
  • Пять книг.
    책 다섯 권.
  • Мно́го люде́й.
    많은 사람들.

лю́ди사람들 → люде́й (복수 생격)

🎯 패턴 연습 (눌러서 확인)

2 + братдва бра́та
3 + сестратри сестры́
5 + книгапять книг
더보기

복수 생격: 남성 +ов (братьев는 예외), 여성 -а → 어미 없음 (книг, сестёр).
