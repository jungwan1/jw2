동사 변화 규칙 (현재형)

🔊 러시아어를 누르면 소리가 나요. 연습 칸은 누르면 답이 보여요.

1. 1형 규칙 -ать / -ять

я-ю (자음 뒤면 -у)
ты-ешь
он/она́-ет
мы-ем
вы-ете
они́-ют (자음 뒤면 -ут)

어간은 그대로 두고 -ть만 떼고 끝을 붙여요.

예) 이 규칙을 따르는 동사

чита́ть → чита́ю
знать → зна́ю
рабо́тать → рабо́таю
ду́мать → ду́маю
понима́ть → понима́ю
де́лать → де́лаю
слу́шать → слу́шаю
отдыха́ть → отдыха́ю
помога́ть → помога́ю
начина́ть → начина́ю
выбира́ть → выбира́ю
гуля́ть → гуля́ю
теря́ть → теря́ю
игра́ть → игра́ю

🎯 패턴 연습 (눌러서 확인)

знать + тыты зна́ешь
рабо́тать + мымы рабо́таем
слу́шать + они́они́ слу́шают
гуля́ть + яя гуля́ю
де́лать + вывы де́лаете
понима́ть + она́она́ понима́ет
더보기

чита́ть 전체 변화

ячита́ю
тычита́ешь
он/она́чита́ет
мычита́ем
вычита́ете
они́чита́ют

과거: чита́л / чита́ла / чита́ли
명령: чита́й / чита́йте

пла́кать + она́она́ пла́чет
маха́ть + они́они́ ма́шут

3. -овать / -евать → -ую

я-ую
ты-уешь
он/она́-ует
мы-уем
вы-уете
они́-уют

-ова-/-ева-가 -у-로 바뀌어요. 외래어 동사가 많아요.

예) 이 규칙을 따르는 동사

рисова́ть → рису́ю
танцева́ть → танцу́ю
путеше́ствовать → путеше́ствую
сове́товать → сове́тую
чу́вствовать → чу́вствую
тре́бовать → тре́бую
организова́ть → организу́ю
ночева́ть → ночу́ю
фотографи́ровать → фотографи́рую
интересова́ться → интересу́юсь
рекомендова́ть → рекоменду́ю

🎯 패턴 연습 (눌러서 확인)

танцева́ть + яя танцу́ю
путеше́ствовать + мымы путеше́ствуем
сове́товать + тыты сове́туешь
чу́вствовать + она́она́ чу́вствует
рисова́ть + они́они́ рису́ют
тре́бовать + вывы тре́буете

4. -авать → -аю (ва가 빠짐)

я-аю
ты-аёшь
он/она́-аёт
мы-аём
вы-аёте
они́-аю́т

-ва-가 사라지고 강세는 끝(-ё-)에 와요. 명령형은 -ва́й.

예) 이 규칙을 따르는 동사

дава́ть → даю́
встава́ть → встаю́
узнава́ть → узнаю́
продава́ть → продаю́
устава́ть → устаю́
отдава́ть → отдаю́
задава́ть → задаю́
признава́ть → признаю́

🎯 패턴 연습 (눌러서 확인)

дава́ть + тыты даёшь
встава́ть + яя встаю́
продава́ть + они́они́ продаю́т
устава́ть + мымы устаём
узнава́ть + она́она́ узнаёт
встава́ть + вывы встаёте

5. 2형 규칙 -ить / -еть

я-ю (ж/ч/ш/щ 뒤면 -у)
ты-ишь
он/она́-ит
мы-им
вы-ите
они́-ят (ж/ч/ш/щ 뒤면 -ат)

모음이 и로 바뀌어요. смотре́ть, сиде́ть 같은 -еть도 여기에 많아요.

예) 이 규칙을 따르는 동사

говори́ть → говорю́
звони́ть → звоню́
учи́ть → учу́
кури́ть → курю́
вари́ть → варю́
смотре́ть → смотрю́
ви́деть → ви́жу
сиде́ть → сижу́
лете́ть → лечу́
ходи́ть → хожу́
проси́ть → прошу́
плати́ть → плачу́
слы́шать → слы́шу
держа́ть → держу́

🎯 패턴 연습 (눌러서 확인)

говори́ть + мымы говори́м
смотре́ть + яя смотрю́
звони́ть + тыты звони́шь
ви́деть + яя ви́жу
ходи́ть + они́они́ хо́дят
сиде́ть + вывы сиди́те
더보기

говори́ть 전체 변화

яговорю́
тыговори́шь
он/она́говори́т
мыговори́м
выговори́те
они́говоря́т

과거: говори́л / говори́ла / говори́ли
명령: говори́ / говори́те

я형에서만 자음이 바뀌어요: д→ж (ви́деть→ви́жу), т→ч (лете́ть→лечу́), с→ш (проси́ть→прошу́), з→ж (вози́ть→вожу́), ст→щ (прости́ть→прощу́). ты부터는 원래 자음!

7. -ся 동사 (재귀)

я-юсь / -усь
ты-ешься / -ишься
он/она́-ется / -ится
мы-емся / -имся
вы-етесь / -итесь
они́-ются / -ятся

먼저 1형·2형으로 바꾸고 끝에 붙여요. 자음 뒤엔 -ся, 모음 뒤엔 -сь.

예) 이 규칙을 따르는 동사

занима́ться (1형) → занима́юсь
одева́ться (1형) → одева́юсь
умыва́ться (1형) → умыва́юсь
возвраща́ться (1형) → возвраща́юсь
называ́ться (1형) → называ́юсь
улыба́ться (1형) → улыба́юсь
учи́ться (2형) → учу́сь
ложи́ться (2형) → ложу́сь
находи́ться (2형) → нахожу́сь
боя́ться (2형) → бою́сь
нра́виться (2형) → нра́влюсь
встреча́ться (1형) → встреча́юсь

🎯 패턴 연습 (눌러서 확인)

занима́ться + яя занима́юсь
занима́ться + вывы занима́етесь
учи́ться + тыты у́чишься
учи́ться + мымы у́чимся
улыба́ться + она́она́ улыба́ется
боя́ться + яя бою́сь
더보기

учи́ться 전체 변화

яучу́сь
тыу́чишься
он/она́у́чится
мыу́чимся
выу́читесь
они́у́чатся

과거: учи́лся / учи́лась / учи́лись
명령: учи́сь / учи́тесь

8. 불규칙: 꼭 외울 동사

자주 쓰니까 통째로 외워요.

예) 이 규칙을 따르는 동사

быть → бу́ду (미래)
хоте́ть → хочу́, хо́чешь, хо́чет, хоти́м, хоти́те, хотя́т
есть → ем, ешь, ест, еди́м, еди́те, едя́т
дать → дам, дашь, даст, дади́м, дади́те, даду́т
идти́ → иду́, идёшь … иду́т
е́хать → е́ду, е́дешь … е́дут
мочь → могу́, мо́жешь … мо́гут
жить → живу́, живёшь … живу́т
пить → пью, пьёшь … пьют
ждать → жду, ждёшь … ждут
брать → беру́, берёшь … беру́т

🎯 패턴 연습 (눌러서 확인)

хоте́ть + яя хочу́
хоте́ть + мымы хоти́м
мочь + тыты мо́жешь
жить + онон живёт
ждать + яя жду
е́хать + мымы е́дем
더보기

과거: шёл/шла/шли (идти́), ел/е́ла (есть), мог/могла́ (мочь). быть 과거: был/была́/бы́ло/бы́ли.
